⏰ 主题1：货币时间价值（4题）

T1. 货币时间价值
复利终值总是大于或等于同等名义利率下的单利终值。
✅ 答案：正确
复利计算中，利息也会再产生利息（即"利滚利"），因此在相同名义利率与期数下，复利终值必定 ≥ 单利终值（仅当 r=0 或 n=0 时二者相等）。
复利与单利的核心区别：复利体现"利息的利息"
T2. 货币时间价值
在其他条件相同时，贴现率越高，未来现金流的现值越大。
❌ 答案：错误
根据现值公式 PV = FV / (1+r)^n，现值与贴现率呈反向变动关系。贴现率越高，分母越大，现值越小。理解这一点是债券定价、股票估值的基础。
现值 vs 贴现率：反方向变动（背道而驰）
T3. 货币时间价值
普通年金的现值等于各期现金流分别贴现后求和。
✅ 答案：正确
这是年金现值的本质。年息金现值系数（PVIFA）就是对"逐期贴现再加总"这一过程的数学化简，便于快速计算。
年金现值系数本质：∑[Cₜ/(1+r)ᵗ]
T4. 货币时间价值
永续年金的现值等于"最后一期"现金流除以必要报酬率。
❌ 答案：错误
永续年金（Perpetuity）没有"最后一期"，因为它永远支付。正确公式为 PV = C / r，其中 C 是每期固定现金流，r 是必要报酬率。常见考点：优先股估值常用此公式。
永续年金公式 PV = C / r（无最后期）

📊 主题2：资本预算决策 NPV / IRR / 回收期（5题）

T5. 资本预算
净现值（NPV）为正的项目应当被拒绝。
❌ 答案：错误
NPV 法的决策规则：NPV > 0 → 接受；NPV < 0 → 拒绝；NPV = 0 → 临界。NPV 为正意味着项目能为股东创造财富（回报超过必要报酬率），必须接受。
NPV 决策规则：正接受、负拒绝、零无所谓
T6. 资本预算
在互斥项目决策中，NPV 法与 IRR 法总是给出相同的结论。
❌ 答案：错误
在独立项目决策中两种方法结论一致，但在互斥项目决策中，由于规模差异、现金流时序差异或多重 IRR，两种方法可能矛盾。出现矛盾时一律以 NPV 为准，因为 NPV 直接衡量股东财富的增加。
NPV 与 IRR 冲突时 → 以 NPV 为准
T7. 资本预算
传统回收期法完全考虑了货币的时间价值。
❌ 答案：错误
传统回收期（Payback Period）只计算收回初始投资所需的名义时间，未对各期现金流进行贴现，因此未考虑货币时间价值。其改进版"折现回收期"才考虑了时间价值。
传统回收期不考虑时间价值；折现回收期考虑
T8. 资本预算
NPV 法隐含的假设是项目产生的中间现金流以必要报酬率进行再投资。
✅ 答案：正确
NPV 法假设中间现金流可以按资本成本（必要报酬率）再投资——这是一个相对合理的假设。IRR 法则假设按 IRR 再投资，可能高估项目价值，这也是 NPV 优于 IRR 的原因之一。
NPV 假设按 r 再投资；IRR 假设按 IRR 再投资（更激进）
T9. 资本预算
盈利指数（PI）大于 1 的项目，其 NPV 必为正。
✅ 答案：正确
PI = 未来现金流现值 / 初始投资。PI > 1 意味着未来现金流现值 > 初始投资，即 NPV > 0。PI 与 NPV 同向决策，二者等价（独立项目下）。
PI > 1 ↔ NPV > 0（充要条件）

📈 主题3：资本资产定价模型 CAPM（3题）

T10. CAPM
β 系数衡量的是资产的全部风险（含系统性风险与非系统性风险）。
❌ 答案：错误
β 只衡量系统性风险（市场风险）。因为非系统性风险可通过分散化消除，资本市场不会对其提供风险补偿。β = Cov(Ri, Rm) / Var(Rm)。
β = 系统性风险；σ（标准差）= 总风险
T11. CAPM
根据 CAPM 模型，市场组合的 β 值恒等于 1。
✅ 答案：正确
市场组合作为系统性风险的衡量基准，根据 β 的定义（自身与自身的协方差除以自身方差），其 β 必为 1。同时无风险资产 β=0。
β 锚点：市场组合=1，无风险资产=0
T12. CAPM
证券市场线（SML）描述单个证券预期收益率与其 β 值之间的线性关系。
✅ 答案：正确
SML 横轴为 β，纵轴为预期收益率，由 CAPM 方程给出：E(Ri) = Rf + βi × [E(Rm) − Rf]。位于 SML 上方的资产被低估（应买入），下方被高估（应卖出）。
SML 是 CAPM 的图形化；CML 是其特殊情况（仅适用于有效组合）

⚖️ 主题4：资本结构与 MM 理论（4题）

T13. MM理论
在不考虑所得税的条件下，MM 理论认为企业价值与其资本结构无关。
✅ 答案：正确
MM 无税模型（命题 I）的核心结论：在完美资本市场下，企业价值由未来现金流的现值决定，与负债/股权比例无关；命题 II 指出 WACC 也与资本结构无关。
MM 无税：价值与资本结构无关
T14. MM理论
考虑所得税后，债务融资可以通过税盾效应增加企业价值。
✅ 答案：正确
利息支出可在税前扣除，产生税盾效应（Tax Shield = 利息 × 税率），降低加权平均资本成本，提升企业价值。这是 MM 有税模型的核心观点。
税盾价值 = 负债金额 × 税率（有税 MM）
T15. MM理论
财务困境成本会随着负债比例的增加而线性递增。
❌ 答案：错误
财务困境成本与负债比例呈非线性关系。低负债时增长缓慢，但超过临界点后急剧上升（直接破产成本 + 间接经营成本，如客户流失、供应商拒合作）。
财务困境成本：非线性，超过临界点急剧上升
T16. MM理论
权衡理论认为，最优资本结构位于"税盾的边际收益 = 财务困境的边际成本"时。
✅ 答案：正确
权衡理论（Trade-off Theory）认为最优资本结构是动态平衡点：继续增加负债带来的边际税盾收益等于边际财务困境成本。题目关键在于"边际"二字。
权衡理论：边际税盾收益 = 边际困境成本

💰 主题5：股利政策（3题）

T17. 股利政策
MM 股利无关理论认为，在完美资本市场下股利政策不影响企业价值。
✅ 答案：正确
MM 股利无关论：完美市场下股利政策与企业价值无关。股东可通过自制股利（卖出部分股票 / 减少投资）实现想要的现金流，公司支付股利减少的现金可通过新股发行弥补。
股利无关论核心："自制股利"使投资者无差别对待
T18. 股利政策
股票回购与现金股利在税务处理上完全相同。
❌ 答案：错误
现金股利通常按普通收入或优惠税率纳税；股票回购的资本利得可递延、按较低税率纳税。因此两者在税务处理上有显著差异，这也是回购近年流行的原因之一。
回购 vs 股利：回购有税务优势（资本利得税率通常更低）
T19. 股利政策
"一鸟在手"理论认为，投资者更偏好确定的现金股利而非未来资本利得。
✅ 答案：正确
Gordon & Lintner 的"一鸟在手"（Bird-in-the-Hand）理论：由于未来资本利得有不确定性（风险），投资者愿意为确定的现金股利支付溢价，因此股利政策与企业价值正相关——这与 MM 股利无关论形成对比。
"一鸟在手" vs 股利无关论：风险偏好观点的根本对立

💵 主题6：债券与股票估值（4题）

T20. 估值
债券的市场价格与市场利率呈反向变动关系。
✅ 答案：正确
根据债券定价公式 P = Σ[息票/(1+r)ᵗ] + 面值/(1+r)ⁿ，当市场利率 r 上升时，所有未来现金流的现值都下降，因此债券价格下跌。反之亦然。
债券价格-利率反向变动是估值最核心规律
T21. 估值
零息债券的当期收益率等于其到期收益率。
❌ 答案：错误
零息债券不支付期间利息，当期收益率 = 年利息 / 当前价格 = 0。而到期收益率（YTM）是使未来现金流现值等于当前价格的折现率，不为零。二者显然不等。
零息债券：当期收益率=0 ≠ 到期收益率
T22. 估值
Gordon 固定增长股利模型假设公司股利以恒定速率永续增长。
✅ 答案：正确
Gordon 模型 P₀ = D₁ / (r − g) 假设股利以恒定增长率 g 永续增长。关键限制：r > g、g 恒定、股利政策稳定。适用于成熟、增长稳定的大型企业，不适合高增长或零增长公司。
Gordon 模型使用前提：r > g 且 g 恒定
T23. 估值
债券的久期越长，其价格对利率变动的敏感度越高。
✅ 答案：正确
久期（Duration）衡量债券价格对利率的敏感性（利率弹性的一阶近似）。久期越长 → 利率风险越大。零息债券的久期 = 到期期限；付息债券久期 < 到期期限。
久期 ≈ 加权平均回收期，是利率敏感度指标

🧮 主题7：加权平均资本成本 WACC（3题）

T24. WACC
加权平均资本成本（WACC）就是各类资本成本的简单算术平均。
❌ 答案：错误
WACC 是按各类资本占总资本比重（市值权重或目标资本结构权重）加权计算的平均资本成本，而非算术平均。公式：WACC = w_d × r_d(1−t) + w_{ps} × r_{ps} + w_e × r_e。
WACC 是加权（按资本结构权重），不是简单平均
T25. WACC
债务资本成本在 WACC 中应按税后成本计算。
✅ 答案：正确
利息支出可税前抵扣，产生税盾效应，因此在 WACC 中债务成本应使用税后成本 r_d × (1 − t)，其中 t 是所得税税率。
债务成本 → 税后；股权成本 → 不调整（股利不可抵税）
T26. WACC
WACC 既可作为公司整体的折现率，也可作为风险匹配新项目的最低必要报酬率。
✅ 答案：正确
WACC 反映公司整体平均的资本成本。一方面用于评估公司整体价值；另一方面，与公司风险相似的新项目可使用 WACC 作为折现率（最低必要报酬率）。但若项目风险显著不同，需调整。
WACC 双用途：公司估值 + 风险匹配项目的折现率

🎲 主题8：风险与收益（2题）

T27. 风险收益
标准差衡量的是资产的总风险，β 系数衡量的是资产的系统性风险。
✅ 答案：正确
标准差 σ 反映资产收益率的整体波动（含系统性 + 非系统性风险）。β 反映相对于市场组合波动的部分，即系统性风险。总风险 = 系统性 + 非系统性。
总风险 = 系统性 + 非系统性；非系统性可分散
T28. 风险收益
资本市场只对系统性风险提供风险补偿，非系统性风险不获得风险溢价。
✅ 答案：正确
根据 CAPM 与分散化原理，非系统性风险可通过充分分散投资组合消除，因此市场不会为可消除的风险提供补偿。只有系统性风险（β）获得风险溢价。
"风险定价之谜"答案：只对不可分散风险定价

🏗️ 主题9：杠杆与财务困境（2题）

T29. 杠杆
经营杠杆通过固定经营成本放大销售收入变动对 EBIT 的影响。
✅ 答案：正确
经营杠杆（DOL）源于固定经营成本的存在。销售收入小幅变动 → EBIT 出现更大比例变动。DOL = 边际贡献 / EBIT = (销售收入 − 变动成本) / (销售收入 − 变动成本 − 固定成本)。
DOL 反映 EBIT 对销售收入变化的敏感度
T30. 杠杆
财务杠杆使每股收益（EPS）的变动幅度小于 EBIT 的变动幅度。
❌ 答案：错误
财务杠杆（DFL）通过固定财务费用（利息）的存在，使 EPS 的变动幅度大于 EBIT 的变动幅度（"以小博大"效应）。DFL = EBIT / (EBIT − I)。
DFL = EPS 变动率 / EBIT 变动率（放大效应）

⏰ 主题1：货币时间价值（4题）

MC1. 货币时间价值
下列关于复利与单利终值的描述中，正确的是：
  • 复利终值总是小于单利终值
  • 复利终值总是大于等于单利终值
  • 单利终值总是大于复利终值
  • 复利与单利终值大小关系不确定
✅ 答案：B
复利考虑"利滚利"。相同名义利率、相同期数下，复利终值 ≥ 单利终值（r=0 或 n=0 时相等）。常见陷阱：把"实际利率"与"名义利率"混为一谈，复利频率越高终值越大。
复利终值 ≥ 单利终值
MC2. 货币时间价值
某项目预期每年产生现金流 1000 元，永续支付。投资者要求必要报酬率 10%，则该永续年金的现值为：
  • 100 元
  • 1000 元
  • 10000 元
  • 11000 元
✅ 答案：C
永续年金现值公式：PV = C / r = 1000 / 0.10 = 10000 元。常用于优先股估值（优先股股利固定支付）、英国国债（Consol）等场景。
永续年金 PV = C / r
MC3. 货币时间价值
一笔年金在贴现率 10% 下 5 年期现值系数为 3.7908。若贴现率提高到 15%，其他条件不变，年金现值会：
  • 增大
  • 减小
  • 保持不变
  • 先增后减
✅ 答案：B
现值与贴现率反向变动。利率从 10% 升至 15%，年金现值系数下降（PVIFA(15%,5)=3.3522），年金现值减小。计算题中只需看贴现率方向即可快速判断。
贴现率 ↑ → 现值 ↓（恒成立）
MC4. 货币时间价值
关于现值（PV）与终值（FV）的关系，下列哪个公式是正确的？
  • PV = FV × (1+r)ⁿ
  • FV = PV / (1+r)ⁿ
  • PV = FV / (1+r)ⁿ
  • PV = FV + (1+r)ⁿ
✅ 答案：C
现值是未来终值的折现：PV = FV / (1+r)ⁿ。B 错误地颠倒了分子分母；A 是终值公式；D 完全无意义。这是估值计算的起点，必须熟记。
PV = FV × 1/(1+r)ⁿ

📊 主题2：资本预算决策（5题）

MC5. 资本预算
在互斥项目决策中，NPV 法与 IRR 法产生矛盾时，应当以哪种方法为准？
  • IRR 法
  • NPV 法
  • 回收期法
  • 盈利指数法
✅ 答案：B
NPV 直接衡量项目为股东增加的财富，是最可靠的资本预算方法。当 NPV 与 IRR 冲突时（多见于互斥项目、规模差异或现金流时序差异），以 NPV 为准。可用增量 IRR（incremental IRR）法辅助验证。
NPV 是"金标准"，与 IRR 冲突时优先 NPV
MC6. 资本预算
下列哪种资本预算方法考虑了货币的时间价值？
  • 传统回收期法
  • 折现回收期法
  • 平均会计收益率法
  • 投资报酬率（ROI）法
✅ 答案：B
折现回收期法使用折现后的现金流计算回收期，考虑了货币时间价值。A、C、D 都是基于会计或名义现金流的方法，未充分考虑时间价值。NPV、IRR、PI、折现回收期是考虑了时间价值的主流方法。
考虑时间价值的方法：NPV、IRR、PI、折现回收期
MC7. 资本预算
某项目的初始投资为 4000 元，未来 4 年每年产生现金流 2000 元，必要报酬率为 10%。该项目的盈利指数（PI）约为：
  • 0.8
  • 1.0
  • 1.5
  • 2.0
✅ 答案：C
未来现金流现值 = 2000 × PVIFA(10%, 4) = 2000 × 3.1699 = 6339.8 元
PI = 现值 / 初始投资 = 6339.8 / 4000 ≈ 1.58 ≈ 1.5
PI > 1 表明项目 NPV 为正，应接受。
PI = 未来现金流现值 / 初始投资
MC8. 资本预算
A 项目需要初始投资 100 万元，未来 3 年现金流分别为 40 万、50 万、60 万。B 项目需要初始投资 200 万元，未来 3 年现金流分别为 80 万、90 万、100 万。必要报酬率 10%。下列判断正确的是：
  • 两个项目的 NPV 都应计算并比较，规模差异不影响决策
  • 由于 IRR 简便，应直接使用 IRR 法
  • 由于 B 规模大，应选 B
  • 由于 A 投资小，应选 A
✅ 答案：A
互斥项目决策必须计算各自 NPV 并比较。
NPV(A) = 40/1.1 + 50/1.21 + 60/1.331 − 100 = 122.76 − 100 ≈ 22.76 万
NPV(B) = 80/1.1 + 90/1.21 + 100/1.331 − 200 = 222.24 − 200 ≈ 22.24 万
此题 NPV(A) 略高于 NPV(B)，选 A；如规模差异巨大，还可用增量 IRR 法（用 B−A）补充判断。
互斥项目必须比较 NPV；规模差异可用增量 IRR 验证
MC9. 资本预算
关于 NPV 法与 IRR 法的比较，下列说法错误的是：
  • NPV 法假设按必要报酬率再投资
  • IRR 法假设按 IRR 本身再投资
  • 对独立项目，二者结论总是一致
  • NPV 法不能用于比较不同规模的项目
❌ 答案：D
A、B、C 都正确。NPV 法既适用于独立项目也适用于互斥项目，可直接比较不同规模项目（直接比较 NPV 数值）。认为 NPV 不能比较不同规模项目是常见误区。
NPV 适用于所有项目，包括不同规模互斥项目

📈 主题3：CAPM（3题）

MC10. CAPM
某股票 β 系数为 1.5，无风险利率为 4%，市场预期收益率为 10%。根据 CAPM，该股票的预期收益率为：
  • 10%
  • 12%
  • 13%
  • 15%
✅ 答案：C
CAPM 公式：E(R) = R_f + β × [E(R_m) − R_f]
= 4% + 1.5 × (10% − 4%) = 4% + 9% = 13%
关键步骤：先算市场风险溢价（10% − 4% = 6%），再乘 β。
CAPM 计算三步：算溢价 → 乘 β → 加无风险利率
MC11. CAPM
在 CAPM 模型中，β 系数衡量的是哪类风险？
  • 总风险
  • 非系统性风险
  • 系统性风险（市场风险）
  • 信用风险
✅ 答案：C
β = Cov(Ri, Rm) / Var(Rm)，衡量资产相对于市场组合的波动性，即系统性风险。非系统性风险可通过分散化消除，不获得风险溢价。总风险用标准差衡量。
β = 系统性风险；标准差 = 总风险
MC12. CAPM
关于 CAPM 的假设，下列不属于其假设的是：
  • 投资者是理性的、风险厌恶的
  • 存在无风险利率，投资者可以无限制借入借出
  • 所有投资者对预期收益和风险的估计一致
  • 市场存在明显的非系统性风险溢价
✅ 答案：D
CAPM 的核心假设包括：理性风险厌恶投资者、单期投资、存在无风险利率、可以无限借入借出、无税收与交易成本、同质预期。市场不存在明显的非系统性风险溢价（因为非系统性风险可分散消除）本身就是 CAPM 的推论，不是假设。
CAPM 假设：理性、同质预期、无摩擦、单期

⚖️ 主题4：资本结构与 MM 理论（4题）

MC13. MM理论
MM 理论（无税版本）认为：
  • 负债越多企业价值越大
  • 负债越多企业价值越小
  • 企业价值与资本结构无关
  • 只有股权融资能提升企业价值
✅ 答案：C
MM 无税模型（命题 I）核心：在完美资本市场下，企业价值由未来现金流的现值决定，与资本结构（负债/股权比例）无关。命题 II 指出：负债增加会同时提升股权成本（财务风险），整体 WACC 保持不变。
MM 无税：企业价值与资本结构无关
MC14. MM理论
考虑所得税后，债务融资能够增加企业价值的根本原因是：
  • 债务成本通常较低
  • 利息可以税前扣除，产生税盾效应
  • 债权人承担更多风险
  • 债务不会稀释控制权
✅ 答案：B
利息支出可在税前扣除，减少应纳税所得额，产生税盾效应（Tax Shield = 利息 × 税率）。税盾降低了加权平均资本成本，从而提升企业价值（MM 有税模型命题 I）。A、C、D 都不是税盾创造价值的核心原因。
税盾价值 = D × t（D=负债，t=税率）
MC15. MM理论
权衡理论（Trade-off Theory）认为最优资本结构是：
  • 负债为零时
  • 负债为 100% 时
  • 税盾边际收益等于财务困境边际成本的点
  • 债务成本等于股权成本时
✅ 答案：C
权衡理论认为债务带来税盾收益，但同时增加财务困境成本（直接破产成本 + 间接经营成本）。最优资本结构是边际税盾收益 = 边际财务困境成本的负债水平。C 准确表述了这一权衡；其他选项都不符合理论。
权衡理论：边际税盾 = 边际困境成本
MC16. MM理论
优序融资理论（Pecking Order Theory）认为企业融资偏好顺序为：
  • 股权融资 → 债务融资 → 内部融资
  • 内部融资 → 债务融资 → 股权融资
  • 债务融资 → 股权融资 → 内部融资
  • 内部融资 → 股权融资 → 债务融资
✅ 答案：B
Myers & Majluf 优序融资理论：信息不对称下，先用内部融资（最便宜、最不会传递负面信号），其次债务融资（对股价冲击小），最后才是股权融资（会被市场解读为股价高估的负面信号）。
优序融资：内部 → 债务 → 股权

💰 主题5：股利政策（3题）

MC17. 股利政策
剩余股利政策（Residual Dividend Policy）的核心特点是：
  • 优先支付稳定现金股利
  • 优先满足投资项目资金需求后，剩余利润再作为股利分配
  • 维持固定的股利支付率
  • 股利与利润同比例变动
✅ 答案：B
剩余股利政策步骤：①确定最优资本预算；②按目标资本结构计算所需权益资金；③剩余利润才用于发放股利。其优点是保持目标资本结构，缺点是股利不稳定（受投资项目波动影响）。
剩余股利：先保投资，后保结构，剩余才分红
MC18. 股利政策
下列哪一项不属于 MM 股利无关理论的假设？
  • 完美资本市场（无税、无交易成本）
  • 理性投资者，可以自制股利
  • 公司股利支付率固定不变
  • 公司投资政策与股利政策相互独立
✅ 答案：C
MM 股利无关论假设包括：完美资本市场、理性投资者、自制股利、固定投资政策、信息对称等。并不要求"股利支付率固定"——支付率变动时该理论仍然成立。这是一道常见陷阱题。
MM 股利无关论不要求支付率固定
MC19. 股利政策
信号理论（Signaling Theory）认为，公司宣布大幅提高现金股利通常意味着：
  • 公司盈利下降，现金紧张
  • 公司管理层预期未来盈利上升
  • 公司面临财务困境
  • 公司股票被市场高估
✅ 答案：B
信号理论认为股利是管理层向市场传递公司前景信号的机制。提高股利传递积极信号（公司预期未来盈利上升、有充足现金流）；降低股利则被解读为负面信号。这是为什么"股利平滑"现象普遍存在。
股利 ↑ → 利好信号；股利 ↓ → 利空信号

💵 主题6：债券与股票估值（4题）

MC20. 估值
某债券面值 1000 元，票面利率 8%（每年付息），期限 5 年，市场利率 10%。该债券的发行价格约为：
  • 924 元
  • 1000 元
  • 1080 元
  • 1100 元
✅ 答案：A
债券价格 = 利息现值 + 面值现值
= 80 × PVIFA(10%, 5) + 1000 × PVIF(10%, 5)
= 80 × 3.7908 + 1000 × 0.6209
= 303.26 + 620.92 = 924.18 元
票面利率(8%) < 市场利率(10%)，债券折价发行。
票面利率 < 市场利率 → 折价；> 则溢价
MC21. 估值
下列关于债券久期的说法中，错误的是：
  • 久期衡量债券价格对利率变动的敏感性
  • 久期越长，债券利率风险越高
  • 零息债券的久期等于其到期期限
  • 久期与到期期限是完全等价的概念
❌ 答案：D
久期 ≠ 到期期限。久期是各期现金流现值加权的回收期，考虑了现金流时间分布和现值权重。Macaulay 久期对付息债券通常小于到期期限（因为早期支付的利息拉低了加权回收期）。零息债券久期 = 到期期限。
久期 ≠ 到期期限（付息债券久期 < 到期期限）
MC22. 估值
在 Gordon 固定增长股利模型 P = D₁ / (r − g) 中，下列描述错误的是：
  • D₁ 是下一期预期股利
  • r 是投资者必要报酬率（折现率）
  • g 是股利的永续增长率
  • 该模型适用于所有公司，包括高增长初创企业
❌ 答案：D
A、B、C 都正确。Gordon 模型仅适用于股利稳定增长的公司（如成熟大型企业），不适用于：① 高增长初创企业（g 难以恒定）；② 零增长或负增长公司（g ≤ 0 或 g = 0 时公式失效）；③ 股利波动剧烈的公司。
Gordon 模型仅适用于股利稳定增长的成熟企业
MC23. 估值
股票价格与必要报酬率的关系是：
  • 同向变动
  • 反向变动
  • 完全无关
  • 同比例变动
✅ 答案：B
根据 Gordon 模型 P = D₁ / (r − g) 或一般现金流贴现模型，必要报酬率 r 上升 → 分母增大 → 股票现值（价格）下降，二者反向变动。这也是债券价格-利率反向规律在股票估值中的体现。
股价 vs 折现率：反向变动

🧮 主题7：加权平均资本成本 WACC（3题）

MC24. WACC
计算 WACC 时，债务成本应当使用：
  • 债券的票面利率
  • 债券的到期收益率（市场利率）
  • 历史平均利率
  • 中央银行基准利率
✅ 答案：B
WACC 计算应使用各类资本机会成本。债务的机会成本是其市场利率（到期收益率 YTM），因为这是债权人要求的收益率，反映了债务的真实资本成本。票面利率可能高于或低于 YTM，不能代表市场成本。
债务成本 → 用 YTM（市场利率），非票面利率
MC25. WACC
某公司资本结构为：债务 40%（税后成本 4%）、优先股 10%（成本 7%）、普通股 50%（成本 12%）。该公司的 WACC 为：
  • 7.5%
  • 8.3%
  • 9.1%
  • 10.5%
✅ 答案：B
WACC = w_d × r_d + w_{ps} × r_{ps} + w_e × r_e
= 40% × 4% + 10% × 7% + 50% × 12%
= 1.6% + 0.7% + 6.0% = 8.3%
注意债务成本已为税后口径，无需再乘 (1−t)。
WACC 加权计算：注意债务税后口径
MC26. WACC
使用公司 WACC 作为新项目折现率的关键前提是：
  • 项目风险与公司整体风险一致
  • 项目为短期项目
  • 项目资本结构与公司不同
  • 项目有确定的现金流
✅ 答案：A
WACC 反映公司整体的资本成本与平均风险水平。只有当新项目的经营风险与财务风险都和公司整体一致时，才能直接使用 WACC 作为折现率。否则需要根据项目风险调整（如高风险项目用更高的必要报酬率）。
WACC 适用前提：项目风险 ≈ 公司平均风险

🎲 主题8：风险与收益（2题）

MC27. 风险收益
关于系统性风险和非系统性风险，下列说法正确的是：
  • 系统性风险只影响个别公司
  • 非系统性风险影响整个市场
  • 系统性风险无法通过分散化消除
  • 非系统性风险无法通过分散化消除
✅ 答案：C
系统性风险（市场风险）影响整个市场，无法通过分散化消除；非系统性风险（公司特有风险）只影响个别公司，可以通过充分分散化消除。市场只为系统性风险提供溢价（CAPM）。
非系统性可分散；系统性不可分散
MC28. 风险收益
两种完全负相关（相关系数 = −1）的资产在投资组合中：
  • 完全消除总风险
  • 完全消除系统性风险
  • 完全消除非系统性风险
  • 无法降低任何风险
✅ 答案：A
当两种资产相关系数为 −1 时，通过适当比例组合可以完全消除总风险（构造出无风险投资组合）。这是投资组合理论的重要结论。但若相关系数为 0 或部分正相关，则无法完全消除。
相关系数 = −1 → 可完全分散风险（理论上限）

🏗️ 主题9：杠杆与财务困境（2题）

MC29. 杠杆
某公司年销售收入 1000 万元，变动成本率 50%，固定经营成本 200 万元。该公司的经营杠杆系数（DOL）约为：
  • 1.25
  • 1.5
  • 1.67
  • 2.5
✅ 答案：C
边际贡献 = 销售收入 − 变动成本 = 1000 − 1000 × 50% = 500 万元
EBIT = 边际贡献 − 固定成本 = 500 − 200 = 300 万元
DOL = 边际贡献 / EBIT = 500 / 300 ≈ 1.67
含义：销售变动 1%，EBIT 变动约 1.67%。
DOL = 边际贡献 / EBIT
MC30. 杠杆
某公司年 EBIT 为 500 万元，利息支出 100 万元。该公司的财务杠杆系数（DFL）为：
  • 1.0
  • 1.2
  • 1.25
  • 5.0
✅ 答案：C
DFL = EBIT / (EBIT − I) = 500 / (500 − 100) = 500 / 400 = 1.25
含义：EBIT 变动 1%，EPS 变动 1.25%。负债越多 → 利息越大 → DFL 越大 → 财务风险越高。可与 DOL 复合得到总杠杆 DTL = DOL × DFL。
DFL = EBIT / (EBIT − I)，与负债水平正相关
